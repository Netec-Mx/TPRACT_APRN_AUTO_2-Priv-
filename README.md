# Taller Práctico Aprendizaje automático supervisado: Regresión y clasificación parte 2

Este taller práctico integrador permite aplicar los contenidos de clasificación del curso sobre un caso de oportunidades comerciales, complementando lo trabajado previamente con regresión. Los participantes utilizarán un único conjunto de datos para estimar el valor esperado de una oportunidad y construir un modelo de regresión logística que determine su probabilidad de conversión. Durante la práctica experimentarán con función sigmoide, función de costo, descenso del gradiente, umbrales de clasificación, fronteras de decisión, sobreajuste y regularización, utilizando un notebook previamente estructurado para ejecutar, ajustar e interpretar los modelos. Como resultado, podrán analizar nuevas oportunidades combinando una estimación numérica con una probabilidad y clasificación de conversión.

  - Descripción: Aplicar regresión y clasificación sobre un escenario de oportunidades comerciales para estimar el valor esperado y la probabilidad de conversión. El participante trabajará sobre un notebook previamente estructurado en Visual Studio Code, donde reutilizará conceptos de regresión y avanzará hacia regresión logística, función sigmoide, costo logístico, descenso del gradiente, umbrales, fronteras de decisión, sobreajuste y regularización. Mediante ejercicios guiados comparará resultados, interpretará métricas y visualizaciones, ajustará parámetros y finalmente utilizará los modelos para analizar nuevas oportunidades y generar una estimación de valor junto con una clasificación de conversión.
