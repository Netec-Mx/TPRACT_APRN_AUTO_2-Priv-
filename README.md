### [Práctica 1. Sistema de predicción y clasificación de oportunidades comerciales](Capitulo01/README.md)

- 📝 **Descripción**: Integrar regresión lineal y regresión logística para estimar el valor esperado y la probabilidad de conversión de oportunidades comerciales. Trabajarás con un conjunto de 900 registros y un notebook previamente estructurado para explorar los datos, separar entrenamiento, validación y prueba, comparar modelos de regresión e interpretar sus métricas. Experimentarás con la función sigmoide, el costo logístico y el descenso del gradiente; ajustarás umbrales de clasificación, analizarás matrices de confusión y fronteras de decisión, e identificarás sobreajuste mediante ejercicios de regularización. Finalmente, combinarás las predicciones de ambos modelos para analizar nuevas oportunidades, exportar resultados y justificar decisiones de seguimiento con revisión humana.

- ⏱️ **Duración estimada**: 105 min.
